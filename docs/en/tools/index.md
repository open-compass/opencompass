# Tools Overview

The OpenCompass `tools/` directory provides scripts for configuration discovery, prompt preview, prediction inspection, API testing, and result analysis. The configuration and directory formats consumed by these tools may change between versions. Run `python tools/<script>.py --help` before use.

- [Discovering and Comparing Configurations](config_discovery.md)
- [Inspecting Predictions and Analyzing Errors](prediction_analysis.md)
- [Analyzing Repetition and Response Length](repeat_and_length.md)
- [Testing APIs and Message Formats](api_and_message_test.md)
- [Notifications and Task Monitoring](monitoring.md)

For the complete prompt preview workflow, see [Prompt Preview and Debugging](../prompt/debugging.md). For handling interrupted tasks, see [Task Recovery and Reuse](../execution/reuse_and_resume.md).
