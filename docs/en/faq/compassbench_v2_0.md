# Introduction to CompassBench 2.0


## Introduction to v1.0
This page provides an overview of CompassBench in support of the annual OpenCompass leaderboard.

The evaluation covers tasks in language, knowledge, writing, reasoning, mathematics, code, long-context understanding, and agent capabilities. Task descriptions and sample questions are provided below.

- The evaluation combines subjective and objective methods, with a protocol designed for each task.
- Reasoning, mathematics, code, and agent tasks use few-shot chain-of-thought prompting.
- For fill-in-the-blank questions, few-shot examples and output-format constraints in the prompt support answer extraction.
- For multiple-choice questions, the wording of the same question is varied to reduce random effects.
- For open-ended questions, the same question is sampled multiple times and assessed along multiple dimensions.

> OpenCompass applies optimized post-processing for objective questions and constrains the response format in the prompt. A response from which no answer can be extracted because the format instruction was not followed is scored as incorrect. Instruction-following evaluation is planned for the next release.
